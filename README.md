# ⚡ Jubayer's FastAPI Playground

Welcome to my FastAPI testing ground! 🚀  
This is where I mess around with **FastAPI**, **Pydantic models**, and **Python decorators** inside Google Colab.

---

## 🛠️ What's Inside?
- 🛣️ **Dynamic Routing:** `@app.get()` & `@app.post()` endpoints
- 🛡️ **Data Validation:** Automatic JSON checks powered by `pydantic.BaseModel`
- 🎯 **Type Hints:** Native Python type validation (`item_id: int`)
- 🌐 **Web Tunneling:** Live Swagger UI hosted via LocalTunnel in Colab

---

## 🚀 How to Run in Google Colab

1. Open `notebook.ipynb` in Google Colab.
2. Hit **Run All**.
3. Open the generated `.../docs` link to test the live API endpoints!
